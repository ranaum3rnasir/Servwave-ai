# Inventory docs

- `catalog-import-template.csv` — the header row the catalog importer (Inventory → Import CSV, `POST /api/price-book/items/import`) accepts, plus one example row. Every column auto-maps in the import dialog; `Name` and `Sell Price` are required, `Kind` is `material` or `service`, `SKU` is the upsert key (a re-import with the same SKU updates the item). `Category` and `Vendor` are matched by name against what your organization already has — case and surrounding spaces do not matter — but a name that is not found is treated differently for each. **A new `Category` is created for you**, so a catalog can be loaded in one pass without setting up its categories first; the import dialog lists the ones it is about to create before you confirm, and the toast reports them afterwards, so check that list for typos. **A `Vendor` is never created** — an unfound vendor is reported ("1 vendor name not found") and that item comes in with no vendor, because a vendor is a real business record with purchase orders and contacts attached and it needs setting up properly first. A blank cell leaves an existing item's link alone rather than clearing it — unlink on the item itself.
